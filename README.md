# 🎀 PerfectWorldArena-KoreanPatch

Perfect World Arena Korean UI Patch  
완미세계 경기 플랫폼 한국어 UI 패치
<br />
<br /> **PerfectWorldArena-KoreanPatch**는 중국 CS2 사설 플랫폼인 **Perfect World Arena / 完美世界竞技平台**의 일부 UI 문구를 한국어로 번역하는 비공식 사용자 패치입니다.
<br /> **PerfectWorldArena-KoreanPatch** is an unofficial Korean UI patch for **Perfect World Arena / 完美世界竞技平台**, a Chinese CS2 platform.

## 🚀 사용 방법 / How to Use
1. Perfect World Arena를 완전히 종료합니다.
<br /> Completely close Perfect World Arena.
2. apply_patch.bat을 우클릭합니다.
<br /> Right-click apply_patch.bat.
3. 관리자 권한으로 실행을 선택합니다.
<br /> Select Run as administrator.
4. 안내 문구를 확인한 뒤 아무 키나 눌러 패치를 시작합니다.
<br /> Read the instructions and press any key to start the patch.
5. 패치가 완료되면 Perfect World Arena를 다시 실행합니다.
<br /> After the patch is complete, restart Perfect World Arena.

## ⚠️ 주의사항 / Notes

* 이 패치는 비공식 사용자 패치입니다.
<br /> This is an unofficial user-made patch.
* Perfect World Arena 업데이트 후 패치가 풀릴 수 있습니다.
<br /> The patch may be reset after a Perfect World Arena update.
* 문제가 생기면 자동 생성된 백업 파일로 복구할 수 있습니다.
<br /> If something goes wrong, you can restore the automatically created backup file.
* 안티치트 우회, 메모리 변조, DLL 주입 기능은 포함하지 않습니다.
<br /> This patch does not include anti-cheat bypassing, memory modification, or DLL injection.
* 일부 중국어 문구는 아직 번역되지 않았을 수 있습니다.
<br /> Some Chinese UI strings may remain untranslated.
