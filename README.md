# 🎀 PerfectWorldArena-KoreanPatch
완미세계 경기 플랫폼 한국어 UI 패치
<br />Perfect World Arena Korean UI Patch  
## 🚀 사용 방법 / How to Use
1. **Perfect World Arena를 완전히 종료합니다.**  
   Completely close Perfect World Arena.

2. **`apply_patch.bat`을 관리자 권한으로 실행합니다.**  
   Run `apply_patch.bat` as administrator.

3. 문제가 발생하면 `restore_patch.bat`을 관리자 권한으로 실행해 백업 파일로 복구할 수 있습니다.  
   If something goes wrong, run `restore_patch.bat` as administrator to restore from the backup file.

## ⚠️ 주의사항 / Notes

- 이 패치는 **비공식 사용자 제작 패치**입니다.  
  This is an **unofficial user-made patch**.

- Perfect World Arena 업데이트 후 패치가 초기화될 수 있습니다.  
  The patch may be reset after a Perfect World Arena update.

- 패치 전 기존 `app.asar` 파일은 자동으로 백업됩니다.  
  The original `app.asar` file is automatically backed up before patching.

- 안티치트 우회, 메모리 변조, DLL 주입, 게임 로직 변경 기능은 포함하지 않습니다.  
  This patch does **not** include anti-cheat bypassing, memory modification, DLL injection, or game logic modification.

- 일부 중국어 문구는 아직 번역되지 않았을 수 있습니다.  
  Some Chinese UI strings may remain untranslated.
